# Пояснительная записка ВКР — как поправить и пересобрать

Итог — `ALT_STORES_VKR.docx` (и `ALT_STORES_VKR.pdf`) в этой папке. Собирается из текстовых файлов по разделам.

## Пересобрать
Дважды щёлкнуть `build.bat` (нужны Python 3.12 и Microsoft Word). Первый запуск сам создаст `.venv` и поставит библиотеки. Скрипт:
1. рисует графики главы III (`charts.py` → `figures/`);
2. собирает Word из разделов (`build.py`), нумерует рисунки, таблицы, формулы и ссылки на литературу;
3. открывает файл в Word, обновляет оглавление и номера страниц, сохраняет PDF (`render.py`).
`build.bat --png` дополнительно сохраняет картинки страниц в `pages/` (для проверки глазами, в git не попадают).
Если в выводе есть строки `ERROR` — сборка остановилась: там написано, что не так (неизвестный источник, нет картинки и т. п.).

## Как писать
- Обычный текст — абзацами через пустую строку. `**жирный**`, `*курсив*`.
- `# Заголовок` — глава (с новой страницы, прописными). `## 2.1. …` — параграф, `### …` — пункт. `# *Заголовок` — без оглавления.
- Список — строки с `- `.
- Рисунок: `![Подпись](docs/diagrams/architecture.png){#fig:arch width=15}` — путь от корня репозитория, ширина в см; несколько картинок в ряд — через `|`. В тексте: `рисунок @fig:arch` → «рисунок 2.1».
- Таблица: строка `Таблица: Подпись {#tab:key widths=2,5,5 font=12}`, сразу под ней таблица `| a | b |`. В тексте: `@tab:key`.
- Формула: `$$ P = median(p1…pn) $$ {#eq:median}`, ссылка `@eq:median` → «(2.1)».
- Ссылка на литературу: `[@kleppmann2017]`, несколько — `[@a; @b]`, со страницей — `[@a, с. 45]`. Номера ставятся сами по порядку в `95_sources.md`.
- Новый источник: строка `- [ключ] Описание по ГОСТ :: ссылка-проверки` в нужной группе `95_sources.md`.
- `[[PAGEBREAK]]` — новая страница, `[[TOC]]` — оглавление, `[[SOURCES]]` — список литературы.
- Титульный лист: `::c` по центру, `::cb` по центру жирным, `::r` справа (блок), `::gap 3` — три пустые строки.
