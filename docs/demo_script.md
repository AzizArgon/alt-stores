# Сценарий живого показа (5–8 минут)

Показ идёт после 7-минутной презентации (`docs/presentation.md`). Основной вариант — публичный сайт https://pcmarket.khudoberdi.uz (сервер, ветка `alpha`). Запасной — локальная копия (`demo.bat`, без интернета), см. «Запасной план».

Главная мысль, которую нужно донести: **«Загружаешь прайс как есть — получаешь стандартную карточку, проверку на подвохи и рыночную цену; а продавцу — ещё и простой учёт».**

## Подготовка

### За день
1. Обновить даты демо-данных на сервере (брони, журнал склада, уведомления станут «свежими», ассортимент и пароли не меняются):
   ```bash
   ssh pcmarket "cd /opt/alt-stores && docker compose exec -T backend python scripts/seed_demo.py --builds-only --no-photos"
   ```
   Полный `seed_demo.py` на сервере **не запускать** — он перетасует ассортимент демо-магазинов.
2. Проверить, что сайт открывается, а контейнеры здоровы: `ssh pcmarket "cd /opt/alt-stores && docker compose ps"` (оба `healthy`).
3. Проверить вход во все аккаунты показа (пароли сервера — `_local\secrets\`):
   - покупатель — `buyer1@example.com`;
   - демо-магазин **Silicon Plus** (3 филиала + склад, «Учёт остатков») — `demo1@example.com`;
   - пустой магазин для загрузки — `live@example.com` (если на сервере его нет — загрузку показывать в демо-магазине **нельзя**, см. ⚠ ниже; тогда загрузку прайса показать локально через `demo.bat`);
   - администратор — на сервере создаётся только командой `scripts/create_admin.py` (`docs/deploy.md`); если админа на сервере нет — админку показать локально (`admin@example.com`).
4. Подготовить файлы на рабочем столе ноутбука:
   - маленький «эффектный» прайс `samples\demo\dirty_price.xlsx` (≈30 строк: сленг, опечатки, ловушки Anti-Fraud);
   - `samples\demo\posts.txt` — посты (пост 5 — сборка ПК с метками);
   - `samples\demo\barcodes.html` — штрихкоды демо-товаров для сканирования с экрана.
5. Один раз заранее прогнать загрузку `dirty_price.xlsx` в `live@example.com` на сервере: разбор попадёт в кэш, и на защите предпросмотр появится за секунды, даже если ИИ медленный. После прогона нажать «Отменить загрузку» (кэш останется, витрина — чистая).
6. Зарядить ноутбук, проверить HDMI и разрешение проектора (лучше 1920×1080, масштаб браузера 100–110 %).

### За час
1. Открыть в **разных окнах** браузера (чтобы входы не мешали друг другу — обычное окно + окно инкогнито + второй браузер):
   - окно 1 (покупатель): главная https://pcmarket.khudoberdi.uz, вход `buyer1@example.com`;
   - окно 2 (инкогнито): кабинет `/seller`, вход `live@example.com`;
   - окно 3 (второй браузер, например Edge): кабинет Silicon Plus `demo1@example.com` → «Склад»;
   - окно 4 (третий браузер или локальная копия): админка `/admin`.
   Вход хранится в браузере, поэтому в одном окне — один аккаунт.
2. В окне продавца заранее открыть страницу загрузки (`/seller/add`) и вкладку «История загрузок» (`/seller/imports`) — там уже есть разобранный прайс (шаг 5 подготовки).
3. Проверить звук (пик сканера) и что колокольчик Silicon Plus показывает непрочитанные.
4. Помнить: **ИИ бесплатный и иногда отвечает 10–60 секунд.** Пока идёт разбор — говорить (текст ниже), не ждать молча. Если разбор не закончился за 30 секунд — перейти к уже разобранной загрузке в «Истории загрузок».

⚠ Файл прайса загружать **только в пустой магазин `live@example.com`**: загрузка полного прайса снимает с продажи всё, чего нет в файле.

## Показ (≈7 минут)

### 1. Покупатель (≈2 мин) — окно 1

| # | Куда нажать | Что сказать |

| 2 | В строке поиска ввести `12400f` → «Найти» | «Один и тот же процессор магазины пишут по-разному: „проц i5 12400f box“, „Intel-Core i5 - 12400F, oem“. Здесь — одна карточка.» |
| 3 | Открыть карточку Intel Core i5-12400F | «Код МХИК — из справочника, характеристики — из строк прайсов, приведены к одному словарю.» |
| 4 | Прокрутить к предложениям | «Все магазины на одной странице. По умолчанию — рекомендованные: проверенный магазин, наличие, свежий прайс. Метки „ниже / выше рынка“ — сравнение с медианой.» |
| 5 | График цены | «Рыночная цена — медиана всех магазинов, история пишется при каждом изменении.» |
| 6 | Показать флаг Anti-Fraud у предложения (если на карточке нет — каталог → видеокарты/память, предложение с жёлтой плашкой) | «Система предупреждает мягко: „уточните у продавца“. Продавец может оспорить флаг.» |
| 7 | Шапка → «Б/у» | «Б/у отдельно от новых, чтобы не портить рыночную цену. Часть объявлений собрана автоматически из публичных Telegram-каналов — без личных данных.» |

## Короткая версия на 5 минут
Выкидывать по порядку, пока не уложимся:
1. Шаг 18–19 (фото и исправления в админке) — оставить только «Жалобы» одной фразой.
2. Шаг 8 (сборка у покупателя) — сказать одной фразой, не открывать.
3. Шаг 15 (продажа) — показать только приёмку.
4. Шаг 13 (пост сборки) — заменить фразой «посты сборок разбираются так же».
5. Шаг 5 (график) — одна фраза на карточке.

Не выкидывать никогда: поиск `12400f` → одна карточка (шаги 2–4), загрузка прайса с подозрениями (10–12), склад сканером (14).

## Запасной план
- **ИИ отвечает долго (больше 30 с).** Не ждать: «Пока ИИ думает, покажу уже разобранную загрузку» → «История загрузок» (`/seller/imports`) → загрузка из подготовки (шаг 5 «За день»), её предпросмотр с плашками. Можно вернуться к живой загрузке в конце.
- **Нет интернета или сервер недоступен.** На ноутбуке запустить `demo.bat` (≈40 с, без ИИ и без интернета: прайс, демо-файлы и посты разбираются из кэша), открыть http://localhost:5173. Аккаунты те же: `live@example.com`, `demo1@example.com`, `buyer1@example.com`, `admin@example.com`, пароль `demo12345`. Сценарий тот же.
- **Что-то сломалось во время показа.** Не чинить на глазах у комиссии: перейти к скриншотам `docs/screenshots/final/` (держать открытой папку в проводнике, просмотр «Крупные значки») — по одному на каждый шаг: главная, поиск, карточка, б/у, сборка, «Мои товары», предпросмотр, склад, брони, колокольчик, админка, телефон, узбекский.
- **Локально что-то не стартует / порт занят.** `stop.bat`, затем `demo.bat`.
- **Держать открытыми заранее:** вкладку с карточкой i5-12400F, вкладку «История загрузок», вкладку «Склад» Silicon Plus, папку скриншотов, `docs/defense.md` (шпаргалка на вопросы).

## Штрихкоды подробно (если спросят)

**Без камеры.** Silicon Plus → «Склад» → «Приёмка». Ввести в поле товара `2900000000018` и Enter — строка; ещё раз — количество 2. Ввести `2900000000995` — окно «Привязать штрихкод», найти любой свой товар — строка добавится. Ввести `2900000000996` — «Код считан с ошибкой» (не сошлась контрольная цифра). На витрине ввести в поиск `2900000000018` — откроется карточка (код подтверждён двумя магазинами). USB-сканер работает без настройки: он «печатает» код и Enter.

**Камера телефона (нужен HTTPS — только на сервере).**
1. На ноутбуке открыть `samples\demo\barcodes.html` — штрихкоды демо-товаров с подписями «подтверждён / не подтверждён / конфликт / не привязан нигде».
2. На телефоне открыть https://pcmarket.khudoberdi.uz/login, войти Silicon Plus (`demo1@example.com`).
3. Меню → «Склад» → «Приёмка» → «Сканировать камерой», разрешить камеру.
4. Навести на штрихкод на экране ноутбука (15–25 см, яркость выше) — сигнал и вибрация, появится строка.
5. Если камера не открылась: «Камера доступна только на защищённом сайте» — адрес не https; «Нет доступа к камере» — разрешить камеру в настройках браузера. В Safari на iPhone первая загрузка распознавания — 1–2 с.
6. Тестовые приходы на сервере можно не отменять: следующий `seed_demo.py --builds-only` вернёт демо-журнал.
