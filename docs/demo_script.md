# Сценарий показа куратору (5–7 минут)

## Подготовка (за 10 минут до показа)
1. Закрыть всё лишнее, запустить `demo.bat` — через ≈1 минуту откроется каталог на http://localhost:5173. Демо работает без интернета: прайс и демо-файлы разбираются из кэша.
2. Держать открытыми папку `samples\demo` (файлы для загрузки) и `samples\demo\posts.txt` (посты для вставки).
3. Аккаунты (тестовые, только на ноутбуке): пустой магазин для живой загрузки — `live@example.com`, демо-магазин с аналитикой — `demo1@example.com`, пароль у обоих `demo12345`.
4. ⚠ Демо-файлы загружать **только в `live@example.com`**: загрузка файла снимает с продажи все остальные товары магазина.

## Запасной план

- **Нет интернета.** Ничего менять не нужно: `demo.bat` разбирает и полный прайс, и демо-файлы, и посты из кэша, курс ЦБ хранится в базе. Пропадёт только живой запрос к ИИ для новых, ещё не виденных строк — такие строки будут отмечены «не распознано» с ценой из файла.
- **Хочется показать живой ИИ** (нужен интернет и лимит): запустить `demo.bat live` — демо-файлы и посты тогда пойдут через правила и реальный ИИ (Gemini, при исчерпании квоты — Groq); разбор займёт 5–30 секунд.
- **Что-то сломалось во время показа.** Закрыть окна серверов, снова запустить `demo.bat` — база восстановится с нуля за ≈1 минуту (предыдущая копия базы сохраняется в `_local\backups\`).
- **Сервер не стартует / порт занят.** Запустить `stop.bat`, затем `demo.bat`.
- **Совсем ничего не работает.** Показать скриншоты из `docs/screenshots/` (`8_*` — каталог, карточка, рынок, предпросмотр) и `docs/defense.md`.

## Штрихкоды (фаза 12.3)

**Без камеры (локально).** Войти `demo1@example.com` → «Сканирование» → «Приход». Ввести в поле товара `2900000000018` и Enter — строка; ещё раз — количество 2. Ввести `2900000000995` — окно «Привязать штрихкод», найти любой свой товар — строка добавится. Ввести `2900000000996` — «Код считан с ошибкой». На витрине ввести в поиск `2900000000018` и Enter — откроется карточка (код подтверждён двумя магазинами); код с пометкой «не подтверждён» из `samples\demo\barcodes.html` — ничего. USB-сканер работает без настройки: он печатает код и Enter, курсор можно не ставить.

**Камера телефона (проверка на сервере после выкладки, нужен HTTPS).**
1. На компьютере открыть файл `samples\demo\barcodes.html` (двойной щелчок) — на экране штрихкоды демо-товаров с подписями «подтверждён / не подтверждён / конфликт / не привязан нигде».
2. На телефоне открыть https://pcmarket.khudoberdi.uz/seller/login и войти демо-магазином Silicon Plus (`demo1@example.com`; пароль демо-магазинов на сервере — в `_local\secrets\`).
3. Меню снизу → «Скан» → «Приход» → «Сканировать камерой». Разрешить доступ к камере.
4. Навести камеру на штрихкод на экране компьютера (ровно, 15–25 см, яркость экрана повыше). Камера закроется сама, прозвучит сигнал (и вибрация), появится строка; второй раз тот же код — количество 2.
5. Навести на «не привязан нигде» — откроется «Привязать штрихкод». Режим «Найти» — карточка товара с остатками по филиалам.
6. Если камера не открылась: «Камера доступна только на защищённом сайте» — адрес открыт не по https; «Нет доступа к камере» — разрешить камеру для сайта в настройках браузера. В Safari на iPhone встроенного распознавания нет — сработает библиотека ZXing, первая загрузка займёт 1–2 секунды.
7. Тестовые приходы на сервере можно не отменять: это демо-магазин; следующий `seed_demo.py --builds-only` при выкладке вернёт демо-журнал и демо-коды.
