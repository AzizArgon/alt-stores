# Схемы для записки и слайдов (фаза 19)

| Файл | Что | Где использовать |
|---|---|---|
| `architecture` | Архитектура: браузер → Cloudflare/nginx → контейнеры web/backend → SQLite, фото, ИИ, курс ЦБ, Telegram, копии | слайд 5, глава 2 |
| `import_pipeline` | Конвейер импорта прайса: файл → markitdown → очистка → кэш → правила → ИИ → нормализация → Anti-Fraud → предпросмотр → публикация | слайд 6, запасной З4, глава 2 |
| `er_main` | ER-диаграмма: каталог, предложения, импорт, мониторинг | запасной З1, глава 2 |
| `er_stock` | ER-диаграмма: филиалы, остатки, журнал движений, ревизии, штрихкоды, брони | запасной З1, глава 2 |
| `er_other` | ER-диаграмма: сборки, Telegram, чат, уведомления, админка | глава 2 (приложение) |
| `usecase` | Варианты использования по ролям | запасной З3, глава 1–2 |
| `dev_process` | Процесс разработки: этапы по датам, метод, ветки и выкладка | запасной З7, глава 3 |

- `*.mmd` — исходник Mermaid (правится как текст, смотреть — https://mermaid.live).
- `*.png` — картинка для Word и PowerPoint (масштаб ×2, белый фон).
- `*.svg` — векторная картинка для браузера (в Word лучше вставлять PNG: подписи SVG сделаны HTML-блоками).
- `docs/architecture.svg` — копия `architecture.svg` (на неё ссылается `docs/defense.md`).

Перерисовать (нужны Node.js и Edge/Chrome):
```bash
npm i -g @mermaid-js/mermaid-cli
mmdc -i architecture.mmd -o architecture.png -b white -s 2
```
Все 35 таблиц базы — `backend/app/db/models.py`; на ER-схемах показаны ключевые поля.
