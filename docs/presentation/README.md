# Презентация к защите ВКР (ALT STORES)

**Готовый файл:** `ALT_STORES_defense.pptx` — 20 основных слайдов (≈ 7 минут) + 10 запасных после «Спасибо».
Копия в PDF — `ALT_STORES_defense.pdf` (запасной вариант, если на компьютере комиссии что-то не так с PowerPoint).
Картинки всех слайдов — папка `preview/` (`slide-01.png` … `slide-30.png`).

## Что где
| Файл | Для чего |
|---|---|
| `slides.yaml` | **все тексты слайдов и текст выступления** (заметки докладчика), время каждого слайда, данные автора |
| `build_pptx.py` | собирает `.pptx` из `slides.yaml`: расположение блоков, цвета, графики |
| `render_preview.py` | делает PDF и картинки слайдов в `preview/` через LibreOffice — для проверки |
| `fonts/` | шрифт Inter (как на сайте), лицензия OFL — можно свободно ставить |

Картинки берутся из `docs/screenshots/final/` и `docs/diagrams/`, цифры — из `docs/experiment.md` (§10, §11) и `docs/testing.md`. Графики — настоящие диаграммы PowerPoint: их можно открыть и поправить прямо в PowerPoint (правый щелчок → «Изменить данные»).

## Как поменять текст (самое частое)
1. Откройте `slides.yaml` в любом редакторе (VS Code, Блокнот).
2. Найдите слайд по `id` (например, `id: results`) и поменяйте нужную строку в кавычках.
   - ФИО, руководитель, вуз, кафедра — в самом начале файла, блок `author:` (сейчас там `[ВПИСАТЬ]`).
   - Текст выступления — поле `notes:` у каждого слайда; время — `time:` в секундах.
3. Пересоберите (см. ниже) и посмотрите картинки в `preview/`: если текст стал длиннее, он может не влезть в блок — тогда сократите.

Можно править и сам `.pptx` в PowerPoint, но **следующая пересборка перезапишет ручные правки**. Если правите вручную — правьте только `.pptx` и больше не пересобирайте.

## Как пересобрать
Один раз поставить (в PowerShell):
```powershell
py -3.12 -m pip install python-pptx pyyaml qrcode pillow pymupdf
```
Собрать презентацию (из корня репозитория):
```powershell
py -3.12 docs/presentation/build_pptx.py
```
Сделать PDF и картинки для проверки (нужен LibreOffice: `winget install TheDocumentFoundation.LibreOffice`):
```powershell
py -3.12 docs/presentation/render_preview.py
```
Если на компьютере установлен PowerPoint, `build_pptx.py` сам пересохраняет файл с **встроенным шрифтом Inter** — презентация выглядит одинаково на любом компьютере. Без PowerPoint шрифт не встраивается: тогда на компьютере для защиты установите шрифты из `fonts/` (двойной щелчок по файлу → «Установить»).

## Перед защитой
- Вписать ФИО, руководителя, вуз и кафедру в `slides.yaml` → пересобрать.
- Взять с собой `.pptx` и `.pdf` на флешке.
- Режим докладчика в PowerPoint (Alt+F5) показывает заметки с текстом и временем: `[0:25 · с начала 0:40]`.
- После слайда «Спасибо» — показ живого сайта по `docs/demo_script.md`; запасные слайды открывать только на вопросы (`docs/defense.md`).
