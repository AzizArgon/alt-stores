# Дорожная карта и промты для сессий

## Цель проекта
Цель: ALT STORES — единая база компьютерной техники Узбекистана. Система приводит прайсы любых магазинов к одному стандарту, чтобы покупатель мог честно сравнить предложения, а рынок стал прозрачнее.
Приоритеты при конфликте интересов: 1) честность и качество базы; 2) покупатель; 3) удобство продавца.
Главные сцены: «хаос → порядок» (прайс или пост → чистые карточки), «поймали обман» (Anti-Fraud), «один товар — все магазины» (сравнение и мониторинг).
Не делаем: доставку и отслеживание доставки; оплату и любые транзакции через сайт; раздел поставщиков («Перспективы развития» реферата); складской учёт за магазин; продажу от имени ALT STORES; конструктор ПК.
Чат — только между покупателем и магазином по товару, сборке или брони; бронь — без оплаты и доставки; карта — адрес магазина и ссылка на Яндекс Карты.

**Срок:** Claude Pro — до 22.11.2026, дальше работы с Claude не будет. Предзащита — декабрь (готовый проект + введение и глава 1 реферата), защита — конец апреля. Заморозка функций — 18.11: что не готово, уходит в «Перспективы развития».
Фильтр для новых идей: укрепляет единую базу или использует её? Если нет — в «Идеи на потом».

Файл для Азиза и для будущих сессий Claude.
Каждый блок «Промт» — первое сообщение новой переписки. Одна переписка = одна фаза.

## Фаза 5.1 — Фильтры по категориям
**Промт:**
> Прочитай CLAUDE.md и docs/roadmap.md, выполни фазу 5.1.

**Задача:**
- Словарь характеристик для каждой категории: фиксированные ключи, типы и допустимые значения/единицы (это ядро «стандартизации»). Минимум:
  - ОЗУ: тип (DDR3/4/5), форм-фактор (DIMM/SODIMM), объём, частота, комплект (1×/2×), ECC;
  - процессоры: бренд, линейка, сокет, ядра/потоки, встроенная графика, BOX/OEM;
  - видеокарты: чип, производитель чипа, объём памяти, тип памяти;
  - SSD: объём, интерфейс (NVMe/SATA), форм-фактор (M.2/2.5");
  - HDD: объём, форм-фактор, скорость;
  - материнские платы: сокет, чипсет, форм-фактор, тип памяти;
  - мониторы: диагональ, разрешение, частота, матрица;
  - блоки питания: мощность, сертификат 80 PLUS, модульность;
  - корпуса, охлаждение, периферия: 2–3 ключевых фильтра.
- Нормализатор: «16GB», «16 ГБ», «16Gb» → одно значение. Правила, парсер и ИИ пишут характеристики только по словарю.
- Пересчитать характеристики существующих товаров (резервная копия БД). Не выдумывать: нет в строке — нет значения (правило «предположений ИИ» сохраняется).
- API: доступные фильтры категории со счётчиками товаров у каждого значения.
- Каталог: при выборе категории появляются её фильтры, счётчики, фильтры в адресе страницы.
- Отчёт: какой % товаров каждой категории получил ключевые характеристики (цифра для диплома).

### Б4 — Готовые сборки от магазинов ✅ (готово 03.11.2026, подробности — `docs/history.md`)

- У каждой детали — уровень точности: «точная модель» (ссылка на карточку), «только характеристики» (по словарю, «производитель не указан»), «не указано»; для видеокарты — «встроенная графика». Обязательный минимум: модель процессора и чип видеокарты (или встроенная графика).
- Продавец: «Мои сборки» — форма по слотам (три уровня), вставка поста текстом (тот же разбор, что у товаров), правка, снять с продажи, удалить; счётчик в «Обзоре».
- Проверки: флаги точных деталей, «название ≠ состав», ℹ «производитель БП не указан», мягкая совместимость (сокет, память, форм-фактор). Справка только внутри магазина: «эти детали отдельно в этом магазине» — если весь состав точный и магазин продаёт каждую деталь.
- Покупатель: «Готовые сборки» в шапке, плитка и блок на главной, фильтры (цена, назначение, Intel/AMD, чип, ОЗУ, состояние, «только с точным составом»), город.

## Идеи на потом
- Справочник моделей процессоров (ядра, потоки, встроенная графика по номеру модели) как третий источник характеристик — «выведено из справочника» (рядом с «указано продавцом» и «выведено правилом», фаза 5.1). Закроет пробел: у Intel в прайсах не пишут число ядер (сейчас ядра есть у 33% процессоров).

- Цена только на картинке поста (OCR) — сейчас такие посты не поддерживаются.
- Подсказка продавцу при сильном отклонении его цены от рынка.
